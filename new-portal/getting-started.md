# Getting Started

Welcome to the new GearHost control panel. This walkthrough covers the
current launch preview, from signing in to creating your first CloudSite.

> Existing GearHost customer? Your current services will stay in the
> existing control panel until GearHost contacts you about migration.

## 1. Sign in or create an account

Go to [octane.gearhost.com](https://octane.gearhost.com). You can use email
or one of the sign-in providers shown on the page. Complete any verification
or account-recovery prompts before continuing.

## 2. Create a CloudSite

A CloudSite groups the services for one domain in a single place.

1. Select **CloudSites** in the control panel.
2. Select **Create CloudSite**.
3. Enter the domain you want to use.
4. Choose the services you need: **Web Hosting**, **Email**, and/or **DNS**.
5. Review the selection and create the CloudSite.

The control panel shows provisioning progress and adds the new CloudSite to
your dashboard when it is ready.

## 3. Add or deploy your website

Open the CloudSite and select **Web**. The controls available for your site
may include:

- File management
- Runtime and application settings
- FTP or deployment credentials
- A publish profile
- DNS and SSL status
- Backups and usage information

Use only the connection details shown for your CloudSite. Availability can
vary by service type while launch testing is in progress.

## 4. Add a database

If databases are enabled for your account, select **Databases** and choose
the available SQL Server or MySQL option. Save the generated connection
details somewhere secure. Do not commit passwords or connection strings
to your source repository.

## 5. Check billing and support

- **Billing** shows the billing information currently available for your
  account.
- **Activity** shows recent account and service events.
- **Support** provides the support options enabled for your account.

## What's next

- Check [Launch Availability](?doc=launch-availability) before relying on a
  preview feature for production.
- Confirm your DNS and SSL status before sending traffic to a new site.
